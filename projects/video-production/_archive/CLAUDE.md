# Retired video pipeline — archive manifest

**Read-only provenance. Never route here to do work, never "fix" anything under
this folder, never load a file here because a task looks video-shaped.** The
repo rule is in `.claude/rules/repo-hygiene.md`; this manifest exists so that a
future session can find a specific retired artifact deliberately, without
crawling 600 MB.

**Retired 2026-08-02.** The illustrated-lesson factory was taken down to a blank
slate at the owner's instruction. Four essentials stayed live under
`projects/video-production/design-system/`:

| Still live | Why it was kept |
|---|---|
| `config/tokens.yml` | HeyGen voice ID + speed, Proxima Nova type scale and 40px floor, brand colors, spacing, program display names |
| `assets/fonts/` | Proxima Nova woff2 400/700/900 + `metrics.json` (measured line-heights) |
| `assets/brand/` | The three SCLA logo SVGs |
| `package.json` | HyperFrames CLI version pin |

`projects/video-production/lesson-scripts/` also stayed live — it is course
content, not machinery.

## What is in here

### `video-production-root/`
The three files that sat at `projects/video-production/`.

| File | What it is |
|---|---|
| `CLAUDE.md` | The pipeline's agent routing table — which file to load per task, which of Synthesia / HeyGen / HyperFrames / Wistia to use per video type, and the "state is the folder" convention. |
| `README.md` | The human-facing door: the two render paths, how to run a batch, the two conventions that confuse newcomers. |
| `PIPELINE-STATUS.md` | The last generated queue snapshot (20 queued, 13 built without an MP4, 1 gate-rejected, 2 blocked on owner input). Generated by `scripts/batch-status.sh --write`; frozen at retirement. |

### `design-system/`
Everything removed from the live design-system folder.

| Path | What it is |
|---|---|
| `compositions/scla-*.html` | The twelve scene templates (title, statement, points, chips, steps, condition, morph, loop, quote, stat, career-map, outro) — sub-compositions instantiated with variables, never forked. This *was* the illustrated look. |
| `index.html` | The demo reel — one scene per template with real lesson content. The living style guide and the target of the template-level gate. |
| `docs/design-contract.md` | The prose authoring contract: animacy, pacing, the anchor/timing contract, the template table, the three style packages (summit / horizon / cadence), motion rotation. No code ever read it; builder agents did. |
| `docs/README.md` | Why the folder ignored the repo's project-layout convention (HyperFrames dictated its shape). |
| `AGENTS.md` / `CLAUDE.md` | The folder's agent entry point (CLAUDE.md was a one-line import of AGENTS.md). |
| `hyperframes.json` / `meta.json` | HyperFrames project config and project metadata. |

### `render-qa/`
The deterministic toolchain — the engine of the pipeline.

| Path | What it is |
|---|---|
| `src/` (23 modules) | `preflight.py` (pre-render blocking gate), `compile_timeline.py` + `build_index.py` (author writes `scenes.json`, tools compute every number and compile `index.html`), `verify_render.py` (post-render stream/duration/resolution check), `synth_narration.py` (HeyGen TTS caller, per-scene wavs + word timestamps), `stem.py` (the naming/lock owner), `tokens.py` (the tokens.yml loader), `boxmodel.py` + `textmetrics.py` (browserless layout math), and fourteen `check_*.py` gates — copy, variety, continuity, geometry, capacity, layout, motion, presence, diversity, slots, text, ink, brand, boundaries. |
| `tests/` (18 files) | The suite that pinned every threshold, so no future session could "fix" a gate by loosening it. Ran in CI as `lint-refs.sh` check 11. |
| `docs/` | Seven dated handoff briefs (self-improving gates, agent-native verdict, autobatch, deterministic rewire, owner-review enforcement, pipeline friction, enforcement rebuild) plus `Pipeline-Build-Proposal` (a saved HTML page). History and rationale — the richest record of *why* the gates ended up as they did. |
| `logs/` | `snag-log.md` (rolling per-session retro) and two rotated archives; `BUILD-LOG-archive-001.md`. |
| `README.md` | The owner's manual for the whole pipeline — the single doc that narrated the end-to-end flow. **Start here if you ever rebuild.** |
| `quarantine.log` | Per-video failure records written by the ship script. |

### `renders-hyperframes/`
Per-video build workspaces — 585 MB, the bulk of this archive.

| Path | What it is |
|---|---|
| `_run/scaffold/` | The pre-initialized workspace every build was copied from (`cp -a _run/scaffold/. <stem>`): the twelve templates, fonts, logos, a copied `tokens.yml`, and an `index.html` with the audio host in place. |
| `_run/BUILD-KIT.md` | The authoring contract handed to each cold build subagent, regenerated per run. |
| 16 `<stem>/` folders | One per lesson. Each holds scene HTML, `scenes.json`, timing JSON, and **synthesized narration** (`assets/voice/*.wav` + word-timing JSON). Thirteen were built and never rendered to MP4. Re-creating one means re-authoring *and* re-synthesizing — the audio cost real HeyGen credits. |
| `README.md` | The workspace lifecycle (active → delivered → pruned in place). |

### `renders-mp4/`
The local MP4 staging tree (`<program-slug>/hyperframes/`) plus its README. Empty
of video: rendered MP4s were never committed — they live on Wistia, with URLs
recorded in `lesson-scripts/refinement-log.md` and `published.tsv`.

### `experiments/agent-native-m2/`
A single 2026-07-30 spike testing template-free ("agent-native") rendering — its
own compositions, QA frame dumps, `PROVENANCE.md` (what it read, ran and
produced) and `PIPELINE-IF-ADOPTED.md` (what the pipeline would look like if
every render used the method). The verdict lives in
`render-qa/docs/HANDOFF-agent-native-verdict-2026-07-30.md`. Its `.thumbnails/`
cache was deleted at retirement.

### `claude-skills/`
The four slash commands that drove the factory, removed from `.claude/skills/`
so they no longer load or trigger.

| Skill | What it did |
|---|---|
| `produce-video/` | The one-call dispatcher: refine → build a pilot → stop for approval → drain the queue. |
| `refine-scripts/` | Batch-refined raw `.txt` scripts into `refined/`, one cold subagent per script, with a mandatory facts pass. |
| `render-lessons/` | The build/render/verify/publish half — AUTO-BATCH, BUILD and SHIP phases, and the environment landmines documented nowhere else. |
| `adversarial-qa/` | The on-demand four-lane gauntlet that tried to break a finished cut. |

### `claude-agents/`
`qa-timing.md`, `qa-layout.md`, `qa-facts.md`, `qa-presence.md` — the four
reviewer-lane agent definitions spawned by `adversarial-qa`. Inert without it,
so they were archived alongside it.

### `claude-rules/video-production.md`
The standing-constraints file that used to auto-load into every session touching
the factory: content fidelity, the pilot gate, naming and filing, copy and
narration rules, layout and geometry, motion, and how a gate must behave — each
claim paired with the mechanism that enforced it or honestly labelled a
convention. **The single densest record of what this pipeline had learned.** Read
this first if the pipeline is ever rebuilt; almost every rule in it was written
after something shipped wrong.

### `scripts/`
The repo-root shell scripts that drove the pipeline, moved here because every
one of them calls something else in this archive.

| Script | What it did |
|---|---|
| `batch-prepare.sh` | Claimed a workspace (`mkdir` as the build lock), copied the scaffold, generated `BUILD-KIT.md`. |
| `batch-precheck.sh` | Authoritative pre-render gate: preflight re-run, per-scene snapshots, low-ink flags, vision review. Exit 3 quarantined. |
| `batch-ship.sh` | Render → verify → file the MP4 → upload to Wistia → record in `published.tsv`. Held the machine-wide render lock; failed soft per video. |
| `batch-status.sh` | Read the queue from disk alone; regenerated `PIPELINE-STATUS.md`. |
| `wistia-upload.sh` | The Wistia upload call (needed `with-secrets.sh`, which stayed live). |
| `archive-lesson.sh` | Pruned a published workspace in place and purged regenerable byproducts. |
| `review.sh` / `preview.sh` | Gated builds and served local previews of the clean ones. |
| `hyperframe-guard.sh` | The `PostToolUse` hook that graded every `scenes.json` / `index.html` write in real time. Its hook registration was removed from `.claude/settings.json` at retirement — left armed, it would have errored on every edit in the repo. |

### `status.md`
A pre-existing archived status doc, frozen 2026-07-15 and superseded by
`PIPELINE-STATUS.md` well before retirement. Oldest thing in here.

## What was disarmed elsewhere, and how to re-arm it

- `.claude/settings.json` — all three PostToolUse video hooks removed. Originals
  are in this repo's git history at that file.
- `scripts/lint-refs.sh` check 11 — now reports "no suite at the live path"
  instead of warning. It grades again automatically the moment a suite exists at
  `projects/video-production/render-qa/tests/run_tests.py`.
- `scripts/check-enforcement.py` — its `GRADED` list dropped the six archived
  docs and `decisions/log.md`. Restore an entry when its doc becomes a live
  promise again.
- Root `CLAUDE.md` — video routing rows replaced with a retirement note.
- `.gitignore` — the video byproduct rules were re-pointed at these archived
  paths; the byproducts are no less local-only for being archived.
