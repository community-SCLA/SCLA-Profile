# Community email generator

Writes in Notion; keeps the reusable SCLA email design and converter here.

The cloud connection is being built. This is not yet a working Notion button.

- [Setup and writing format](docs/setup.md)
- Run the repository checks with `bash scripts/lint-refs.sh` from the repository root.

Only synthetic examples belong in tests. This public repository is not a draft or email archive.
